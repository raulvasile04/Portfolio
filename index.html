BookCommunity

A desktop application built with Java and JavaFX that allows users to manage their personal book library, track reading progress, and analyze their reading habits.Built as a group project with two colleagues, this application was developed as part of our Developer Tools course. It was also presented at the annual SemCon meeting.

Key features

  • Add and manage a collection of books
  • Track reading progress (pages read per month/year)
  • View statistics such as most-read genres
  • Simulated multi-user system with locally stored user profiles
  • Interactive JavaFX UI with dynamic data updates

Tech-Stack

  • Java
  • JavaFX

My contribution

Implemented the connection between the UI and application logic, ensuring that user interactions correctly trigger and update underlying data.

Finance Buddy

A full stack personal finance management application built with vanilla JavaScript, HTML and CSS on the frontend and a RESTful API powered by Node.js and Express on the backend, with a PostgreSQL database for persistent data storage.

Key features

  • Income and expense tracking with automatic monthly grouping
  • Live currency conversion via external API integration
  • RESTful backend with full CRUD operations
  • PostgreSQL database for persistent transaction storage
  • Responsive UI with horizontal drag scroll system

Tech-Stack

  • HTML
  • CSS
  • JavaScript
  • Node.js & Express.js
  • REST API
  • PostgreSQL
